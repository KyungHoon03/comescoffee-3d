## 설정 창 (2026-11-01 추가)
- 오른쪽 위 `설정`: 전체 소리, 음악, 공간음, 브루잉 소리, 백그라운드 재생, 조작 방법. 산사의 설정 구성을 따랐습니다.
- 곡 추가는 파일 선택 또는 화면에 끌어다 놓기입니다. 추가한 곡은 방문자 브라우저의 IndexedDB(`comes-music`)에만 저장되고 서버로 올라가지 않습니다. 다른 기기나 다른 브라우저에는 없습니다.
- 설정값은 localStorage `comes.settings`에 저장합니다. 곡이 여러 개면 끝날 때 다음 곡으로 넘어갑니다.
- 확인 완료: 로컬 서버에서 추가·빼기·새로고침 유지·깨진 파일 건너뛰기·곡 파일 없는 상태·375px 화면. 미확인: 귀로 듣는 음질, 실제 휴대폰, 게시된 Claude 페이지에서의 곡 추가.
